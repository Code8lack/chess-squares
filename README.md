# ♞ Chess Squares

A simple web app to train chessboard square color recognition. Learn which squares are dark and light on a chessboard.

## 🎯 How to Play

1. A chess square (e.g., "A1", "H8") is displayed
2. Tap DARK or LIGHT to answer
3. Get instant feedback and track your score
4. New square appears every 3.5 seconds

## 🧠 Why?

Chess notation requires knowing square colors quickly. This trainer helps build that intuition.

## 🛠️ Tech

- HTML5
- CSS3 (responsive, mobile-first)
- Vanilla JavaScript

## 📱 Play Anywhere

Works on:
- Desktop browsers
- iPad / iPhone
- Android devices
- Any device with a modern browser
